Important Notes:

  • PDF files must contain a readable text layer. Scanned PDFs requiring OCR are not currently supported.
  • PDF files are limited to 100 pages and 120,000 characters.
  • CSV and XLSX files are limited to 1,000 rows.
  • Only .xlsx files are supported. The older .xls format is not supported.
  • CSV/XLSX files must contain the following columns: model, manufacturer and category.

Web URL Extraction

Enter a publicly accessible datasheet URL. The system will attempt to retrieve and process its content.

Important Notes:

  • Enter a valid HTTP or HTTPS URL.
  • The webpage must allow access by the system.
  • The system follows robots.txt rules and backend network security restrictions.
  • The current rule-based extraction mode mainly identifies explicit component models and parameter key-value pairs.
